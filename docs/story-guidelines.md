# 物語の書き方

## 形式

- 本文 **250〜280字**（句読点込み）。2〜3段落。いまの声（話速1.0）で約45〜52秒になる（decisions.md D-006・D-011）。
  - これに前後の無音2秒と、文の間0.5秒・段落の間0.8秒が足される。文を細かく分けすぎると、そのぶん長くなる。
  - 58秒を超えると話速を上げて作り直し、`speed_max`（1.15）でも収まらなければ tts が止まる。
- 声：JSON の `"voice"` に、雰囲気に合う声を `config.yaml` の `voices` から選んで書く（例：`"ofutonp"`）。書かなければ `tts.default_voice`。
  - Claude が選ぶ。合わなければ、人が動画CHECK で言う（物語CHECK はしない。D-018）。
- 構成：**冒頭の引き → 状況 → ひねり → 最後の1文でオチ**。
- 冒頭の1文で「何かおかしい」と思わせる。説明から入らない。
- 登場人物は1〜2人。固有名詞は最小限（読み上げで聞き取りにくいため）。
- 耳で聞いて分かる文にする：1文は40字以内、同音異義語や難読漢字を避ける。

## 生成するとき（Claude Code セッション内）

- 20〜30本ずつまとめて生成し、`stories/draft/` に JSON で保存する。
- テーマやジャンルを指定して偏りを避ける（SF、日常の不思議、ブラックユーモア、ほっこりなど）。
- 既存の作品の筋やオチを流用しない。作家の名前を挙げて「〜風に」と指示しない。

## 書いたあとに確かめる点

物語CHECK はしない（decisions.md D-018）。Claude が自分でこの点を見て直してから `approve_story.py` で承認し、人は動画CHECK で判断する。

- [ ] オチで「おっ」となるか。予想どおりなら落とすか直す
- [ ] 冒頭の1文で続きが気になるか
- [ ] 声に出して読んで、つっかえる箇所がないか
- [ ] 既存の有名作品に似すぎていないか
- [ ] 不快な表現、実在の人物・団体への言及がないか

`scripts/approve_story.py` が `approved: true` にして `stories/approved/` に移す（検査に NG があると移さない）。
