# BGM のルール

## TuneCore Japan の Content ID に登録できない曲

TuneCore Japan のヘルプ「【YouTube コンテンツ収益化サービス】登録できない楽曲は？」より（要点）：

- フリー素材などの音源を含む曲（GarageBand のループ音源素材、効果音素材、**生成AI楽曲**など）
- 第三者が権利を持つ音源を含む曲（サンプリング音源、ライセンス音源）
- オリジナル曲のカラオケ、アカペラ、インスト、**ショート**、リマスター、ライブ版
- カバー曲、パブリックドメインの曲
- ゲームのサウンドトラック

申請前に必ず最新の規約を確認すること。

## 作り方の方針

| 役割 | 担当 |
|---|---|
| メロディ・和音・構成（作曲） | **ユーザー**。REAPER のピアノロールで打ち込み、MIDI で書き出す |
| 音色（シンセエンジン）・レンダリング | Claude と一緒に numpy で作る |
| 生演奏（ギターなど） | ユーザー。最も確実に「人の作品」として扱われる |

- Claude にメロディや和音を考えさせない（生成AI楽曲扱いを避ける）。
- MIDI を SoundFont で鳴らさない。numpy のシンセで WAV に直接書き出す。
- 作曲の証拠を残す：REAPER のプロジェクトファイル、日付つきの MIDI、git の履歴。

## 曲の仕様

- 長さ **2:00〜3:00**。A→B→A など展開をつける（単純なループにしない）。
- **冒頭 0:00〜0:60 だけでも1曲として成立する**ように作る（ショートで使う部分）。
- 配信するのは完全版だけ。60秒版を別の曲としてリリースしない（「ショート」版は登録対象外）。
- 書き出し：WAV 44.1kHz / 16bit 以上、−14 LUFS 前後。
- ジャケット画像も自作する。

## 申請と検証の手順

1. 特徴のはっきりした1曲を選び、TuneCore Japan で配信と Content ID を申請する。
   - 配信先を個別に選べるプラン（体験談ではスタンダード以上）か、Pay Per Release かを料金で比べて決める。
   - 自分のチャンネルを除外リストに入れない。
2. 審査の結果を docs/decisions.md に記録する。断られたら理由を記録し、作り方を見直す。
3. 通ったら、BGM の音量を −14 / −18 / −22 dB にした3本を限定公開で上げ、申し立てが付く音量の下限を確認する。結果を `bgm_gain_db` の初期値にする。
4. 数本投稿して、TuneCore 側に収益が計上されるかを確認する。
