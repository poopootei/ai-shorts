# 新しいチャンネルの案

2つ目以降のチャンネルの候補。どれを始めるかは未決定（decisions.md の「未決定」）。始めると決めたら、そのチャンネルの channel.md を作り、ここから移す。
扱う場所はこのリポジトリ（D-015）、アニメーションは Remotion で試作する（D-016）。

## 進め方の方針（2026-11-21）

- **まずはショート（59秒以下）だけで攻める。** 長尺（朗読まとめなど）は、チャンネルに人気が出てから考える。
- AI で作るチャンネルが続くかどうかは、**人が足しているもの**がはっきりしているかで決まりやすい。どの案も「何を人が足すのか」を決めてから始める。
- YouTube は、同じ型で大量に作った動画を「inauthentic content」（2025年7月に repetitious content から改名）として収益化の対象から外す。テンプレートで数字や単語だけを替える作り方は避ける。

## 競合のまとめ（2026-11-21 に調査）

YouTube の検索結果（ログインなし）から拾ったもので、すべてを網羅してはいない。登録者数・再生数は調べた時点の表示。詳しくは各案の「競合」。

| 案 | 競合 | 空いているところ |
|---|---|---|
| 数秘術＋物語 | 多い。日替わりの「今日の数字」は混んでいて、再生は少ない | 物語と組み合わせたものはほぼない。「あなたは？」と問いかける型と合わせる |
| コント＋あるある | とても多い。小さい新しいチャンネルが大量にある | キャラクターと、絞った業界。あるあるだけでは埋もれる |
| 青空文庫の紹介（日本向けは一旦やめた） | 朗読は多い。1分の紹介はほどほど | 作家の人生と作品の紹介。朗読が中心のものは伸びていない |

競合の多さで見ると、数秘術＋物語と青空文庫の紹介が始めやすい。コントは、キャラクターの案が固まってから。

## 案1：数秘術 ＋ 物語

### 中身
- その日・その月のナンバー（日付の数字を足して1桁にしたもの）をテーマに、毎日1本。例：2026-11-21 → 2+0+2+6+1+1+2+1 = 15 → 1+5 = **6の日**。
- 「今日は6の日。6は『世話焼き』の数字」と紹介したあと、その数字の性質を持つ人物の30秒ほどのショートショートにつなげる。
- 日替わりとは別に、日付に縛られない「誕生数3の人の取扱説明書」のようなシリーズも混ぜる。

### いいところ
- 日付と数字の組み合わせで、ネタが尽きない。予約投稿と相性がよい。
- 素材は数字の文字アニメで済む。Remotion がいちばん得意な種類の動画。
- 落ち着いた BGM が前に出るので、Content ID の考え方（D-001）に合う。
- 物語を付けることで、数秘術だけの動画と差がつく。今のチャンネルの物語づくり（write-stories、story-guidelines.md）がそのまま使える。人が足すものは「物語を選んで直すこと」になり、上のポリシーの心配も薄くなる。

### 懸念点
- **日付つきの動画は翌日には古くなる。** 長く再生され続けるのは、日付に縛られないシリーズのほう。両方の割合を決める。
- **占い系のショートは競合が多い。** 物語を付けても埋もれないか、試作で確かめる。
- **数字の意味がぶれないようにする。** 1〜9 とマスターナンバー（11・22・33）の意味の一覧と、計算の規則（マスターナンバーを1桁にまとめるかどうか）を先に決めて、ファイルに固定する。
- **占いであることを明記する。** 断定や、健康・お金について不安をあおる言い方はしない。説明文に「エンターテインメントとして」と書く。
- 物語は 30 秒ほどに短くなるので、250〜280字の指針（D-006）とは別の字数の目安が要る。

### 競合（2026-11-21 に調査）
- **チャンネル**：上位は、鑑定士や講師が顔を出して講座・鑑定へ誘導する型。はづき虹映の数秘チャンネル（2.88万人）、AZチャンネル（1.57万）、エナエナの数秘de大開運チャンネル（1.09万）、KUMI 宇宙の数秘（1.07万）、3necos・橙花（6千前後）。
- **日替わりの「今日の数字」は、すでにある**：「天使の数秘術 2026年11月14日 今日の数字『8』」「11/15は8の日」「星よみAI」（AI で作っている）など。再生はほとんどが数十〜数百回。日付つきの動画は伸びにくい、という懸念どおり。
- **伸びているのは「あなたは？」と問いかける型**：「生まれつき試練が多い人の誕生日は？」61万回、「本命になれる確率とその結果」2.2万回、「あなたが絶対勝てない相手」1.2万回、「ライフパスナンバー7はこんな人」3千回、「誕生日でわかる○○ランキング」1〜4千回。
- **数秘術 × 物語は、ほぼ見当たらない**：近いのは「まほろば数秘（若き武士×巫女）」1,290回、数秘術のショートアニメ 74回くらい。枠は空いているが、見たい人がいるかは分からない。
- **考えられる手**：日替わりを柱にせず、「誕生数7の人に起きた、ちょっと不思議な話」のように、問いかけと物語を組み合わせる。
- 検索した言葉：「数秘術」（チャンネル）、「数秘術 #shorts」、「今日は8の日 数秘」、「数秘術 物語 ショートショート」。

### 次に決めること
- 数字の意味の一覧と計算の規則
- 1本の構成（紹介と物語の秒数の配分）
- 日替わりと、日付に縛られないシリーズの割合

## 案2：コント ＋ サラリーマンあるある

### 中身
- 2人のキャラクターが掛け合う 30〜45 秒のアニメーションのコント。「Fラン大学就職チャンネル」「コンサルのリアル」のような職場ものの、ショート版。
- テーマはサラリーマンのあるある。型（「建前と本音」「面接官の心の声」「業界用語の翻訳」「新人とベテランのずれ」など）× 場面 × オチ で台本を作る。
- **ネタは Twitter（X）から拾う。** よく話題になっている「あるある」を集め、それをもとに自分たちで台本を書く。

### いいところ
- あるあるは共感されやすく、コメント欄が盛り上がる。チャンネルが育てば、コメントそのものがネタの源になる。
- 型があるので、Claude が下書きを20本出し、人が3本選ぶ流れが作れる。
- 2人の声は、今の音声合成（COEIROINK・AivisSpeech）で足りる。口パクは、モーラごとの長さか wav の音量から作れる（D-016）。

### 懸念点
- **Twitter のネタは、そのまま使わない。** 投稿の文章や、特定の人のオチをまねると、盗用や著作権の問題になる。拾うのは「よくあるテーマ」までにして、台本は自分たちで書く。特定の人の体験談を使うなら、本人の了承を取る。
- **Twitter からの集め方。** X の API は有料で（CLAUDE.md の1）、自動で集めるのは規約で禁止されている。人が見て、気になったものを手でメモする。
- **職場ものの枠はすでに混んでいる。** 業界や視点を絞って差をつける。候補：「上司がAIにハマった職場」「AI導入を任された現場」など、自分の経験が使える分野。
- **素材のライセンス。**
  - いらすとや：商用利用は1つの制作物につき20点まで無料（だったはず。使う前に最新の規約で確かめる）。使っているチャンネルが多く、見た目で覚えてもらいにくい。
  - 「アニメ素材」：何を使うかで、ライセンスの確認が別に要る。
  - SVG のコードで描く自分のキャラクターなら、ライセンスの心配がなく、チャンネルの顔として覚えてもらえる（D-016）。
- 実在の会社名・人名は出さない。特定の職業を見下す笑いにしない。
- 台本の形式（話者・セリフ・表情・間）と書き方の指針がまだない。

### 競合（2026-11-21 に調査）
- **大きいチャンネルは、決まったキャラクターや世界観が強い**：ぼくわたチャンネル（102万人、アニメコント、毎日投稿）、いくとん（77.2万、可愛いあるあるアニメ）、そんな奥さんおらんやろ（49.2万、夫婦のアニメコント）、サラリーマンな日常【あるある】（32万、会社が作っている。長尺が中心）、マボドフ（5.52万、シカとカエルとペンギン）、京都弁アニメ 大文字ミヤコ（4.83万）、新入社員シバくんの成長日記（2.17万、柴犬の新入社員）、アニマル課長のセイタイ系（2.07万、動物 × 体の不調）。
- **同じ案の小さいチャンネルがとても多い**（ほとんどが登録者2〜400人）：うう【会社員アニメ】、まいにちあるある劇場、帰れない課（新人SE）、はたらく小劇場、理不尽と戦う青木さん、1分サボり、シゴデキ女子の番場さん、飲食店の裏側アニメ 元店長 など。
- **AI の角度も取られている**：ツッコミ課（「AIに全部まる投げする後輩」）、大手メーカー勤務（大企業の文化を AI と笑う）。
- **考えられる手**：サラリーマンあるあるだけでは埋もれる。伸びているチャンネルは、あるあるより先に「キャラクター・方言・動物」で覚えてもらっている。自分の経験がある業界に絞り、そのうえで覚えやすいキャラクターを作る。
- 検索した言葉：「サラリーマンあるある アニメ」（チャンネル）、「職場あるある アニメ コント」（チャンネル）。

### 次に決めること
- 絞る業界・視点
- キャラクターの見た目（SVG で描くか、素材を使うか）
- 台本の形式と、ネタのメモの置き場

## 案3：青空文庫の紹介

**2026-11-23 日本向けは一旦やめた**（decisions.md D-017）。試作3本と `channels/aozora/` は残し、海外向けの「物語で学ぶ日本語」の素材にする。

### 中身
- 青空文庫にある、著作権の切れた作品を1分で紹介する。あらすじ、作品の一節の朗読、読みどころ。
- 作家の候補：夢野久作、小川未明、新美南吉、芥川龍之介、宮沢賢治など。とても短い掌編なら、まるごと朗読もできる。

### いいところ
- 人が書いた名作なので、AI 量産の心配がない。人が足すものは「作品を選ぶ目」と「読みどころの紹介」。
- 今の仕組み（朗読・字幕・背景・BGM）がほぼそのまま使える。
- 作品の数が多く、ネタが尽きない。

### 懸念点
- **著作権の切れていない作品も、青空文庫にはある。** 作者の許可を得て公開している作品は、商用利用できないことがある。日本では、1967年以前に亡くなった作家の作品は著作権が切れている（1968年以降に亡くなった作家は、死後70年まで保護される）。作品ごとに確かめる。
- **翻訳ものは、訳者の著作権が残っていることがある。** 原作者ではなく、訳者の没年で確かめる。
- 青空文庫のファイルの取り扱い規準を確かめ、底本と入力・校正した人の情報の載せ方を決める。
- 旧字・旧仮名や古い言い回しを、音声合成が読み間違えやすい。読みの直し（fix-readings）の手間が増える。
- 古典は冒頭の「つかみ」が弱くなりやすい。hook の作り方を工夫する。
- 1分に収まる作品は限られる。抜粋するなら、区切り方が大事。

### 競合（2026-11-21 に調査）
- **朗読のチャンネルは多く、ほとんどが長尺**：朗読カフェ（3.58万人、俳優が朗読）、朗読散歩 / いやしのおと（8,310）、ラヴクラフト ライブラリー（6,490）、青空朗読（939、プロのアナウンサー）。機械音声や AI のチャンネル（青空文庫 朗読チャンネル 165、書香玲瓏 18）は小さいまま。
- **ショートで伸びているのは、朗読より「1分でわかる」紹介**：「1分でわかる三島由紀夫の生涯」65万回、「1分でわかる太宰治の生涯」21万回、「1分でわかる『こころ』」13万回、「1分でわかる『金閣寺』」4.4万回、「1分でわかる『山月記』」3.3万回。
- **朗読そのものは伸びていない**：夢野久作「蛇と蛙」の1分朗読 813回、AI で作る「1分de名作小説」は登録者11人。
- **考えられる手**：「紹介」の方向が合っている。作品のあらすじに加えて、作家の人生（ドラマが強い）も題材にする。
- 三島由紀夫（1970年没）のように著作権が切れていない作家も、あらすじの紹介はできる。本文を長く読むのは、著作権の切れた作品に限る。
- 検索した言葉：「青空文庫 朗読」（チャンネル）、「文豪 名作 1分 紹介 #shorts」。

### 次に決めること
- 紹介が中心か、朗読が中心か
- 作品を選ぶ基準と、著作権を確かめる手順

## 見送った案（2026-11-21）

あとで見直すときのために残す。

- 意味がわかると怖い話：ショートショートの技術が使えるが、競合が多い。
- 1分ミステリー：続きを見に来てもらえるが、謎の質を保つのが大変。
- 架空のニュース・架空のCM：本物のニュースと誤解されない見せ方が要る。
- 英語版ショートショート：英語の声（ローカルで動き、ライセンスを確かめたもの）が要る。
- 寝る前の朗読まとめ（長尺）：Content ID の収益は長い動画のほうが大きいが、長尺は人気が出てから（上の方針）。
