# チャンネル運用

このリポジトリが扱うチャンネルの情報と、運用の方針。説明文などを変えたら更新する。

## 基本情報

| 項目 | 内容 |
|---|---|
| 名前 | ショートショートの世界へ |
| URL | https://www.youtube.com/@ショートショートの世界へ |
| 内容 | 約1分で聴ける朗読ショートショート（YouTube Shorts） |
| 投稿 | 手動。YouTube Studio の予約投稿で、毎日決まった時間に公開する（policy.md） |
| 収益 | 主に自作BGMの Content ID（bgm.md）。ショートの広告収益は狙わない |

## 運用の分担

- Claude：説明文・プロフィール・タイトルなどの案づくり、投稿の記録、ボツと改善案の振り返り、方針の整理。
- ユーザー：YouTube Studio での設定の変更と投稿。動画CHECK・物語CHECK の判断。
- YouTube Data API や自動投稿は使わない（decisions.md D-003）。

## 競合（2026-11-21 に調査）

YouTube の検索結果（ログインなし）から拾ったもので、すべてを網羅してはいない。登録者数・再生数は調べた時点の表示。このときの自分のチャンネルは登録者4人。

**まとめ：同じ型のチャンネルは多いが、どこも小さく、目立って勝っているところはない。** 代わりに、ショートショートの朗読を見に来る人そのものも少なそう。

### 同じ型のチャンネル（1分の朗読ショートショート）

| チャンネル | 登録者 | 中身 |
|---|---|---|
| 毎日ショートショート | 表示なし | 60〜90秒の朗読、毎日更新 |
| オトノベ | 60 | 1〜3分の朗読、最後の一行で反転 |
| 最後の一行-人怖朗読- | 15 | 人が怖い話 |
| 一分文庫 | 5 | 1分のオリジナル、最後の一行で反転 |
| 摩訶不思議なショートショート物語 | 5 | AI が書いている |
| 裏返り夜噺 | 4 | 最後に話が裏返る |

- ほかにも「ヨミノアト」「120秒の朗読会」「短編SFショートショート」（AI 編集）など、登録者1桁のチャンネルが多い。
- 同じ型のショートの再生は、多くても千回ちょっと。「透明人間の憂鬱 ―最後の一行で、すべてが反転する。」1,187回、「毎日、母から連絡がくる｜1分ショートショート」1,123回、「【1分小説】未来」764回。ほかは数回〜数百回がほとんど。
- **「1分」「最後の一行で反転」は、もう決まり文句になっている。** AI で作る新しいチャンネルが同時にたくさん出てきている。

### ショートショートで続いているチャンネル

ほとんどが本物の作家。本を出している作家でも登録者は数千人で、ショートショートの朗読は、もともと小さい市場と考える。

| チャンネル | 登録者 | |
|---|---|---|
| 小説家・小狐裕介の小説朗読チャンネル | 6,680 | 本を出している作家 |
| 朗読屋ねむねむ | 4,040 | 長尺。「星新一っぽいショートショート詰め合わせ」が25万回 |
| 奇妙な小説朗読チャンネル | 1,700 | ショートショート作家のオリジナル |
| 田丸雅智【ショートショート研究室】 | 1,070 | 有名なショートショート作家 |

### 再生が集まっている近いジャンル：シニア向けの感動話・スカッと話の朗読

- 1万人を超えるチャンネルが多い：シニアの生活物語（5.64万）、【スカッと朗読】シニアドラマ館（2.56万）、人生、ここから（1.56万）、シニアの心をほぐす物語（1.47万）、人生の摂理（1.32万）、おかげさま映画館（1.22万）など。
- ショートも伸びている：「父の葬儀で金の話をした弟と絶縁。半年後、開けずにいた封筒の中には…」10万回。同じ型が2〜5万回ずつ出ている。
- AI で量産している気配が強く、YouTube の量産への取り締まり（inauthentic content）にいちばん引っかかりやすいジャンルでもある。
- **学べる点**：伸びているショートは、見る人がはっきりしていて（50〜70代）、タイトルに具体的な状況と、続きが気になる一言が入っている（「半年後、封筒の中には…」）。

### このチャンネルへの示唆

- 強いチャンネルがいないので、質と続ける力で上に出られる余地はある。
- ジャンルの需要は小さめ。広告収益を狙わず BGM の Content ID で稼ぐ方針（decisions.md D-001）には合うが、再生数を大きく伸ばすには工夫が要る。
- すぐ試せること：
  1. **タイトルを具体的にする。** 例：「4.5階」→「エレベーターに、ないはずの『4.5階』のボタンがあった」。物語は変えずに、タイトルの付け方の違いを比べられる。
  2. **見る人と感情を絞る。** 「ゾッとする」「泣ける」「ほっこり」のどれで覚えてもらうかを決める。
- 判断するのは、30〜50本を出してから。
- 検索した言葉：「ショートショート 朗読」（チャンネル）、「ショートショート 朗読 1分 #shorts」、「どんでん返し 短編 物語 朗読 #shorts」、「シニア朗読 短編朗読」（チャンネル）、「1分 物語 朗読 最後の一行」（チャンネル）。
