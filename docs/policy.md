# 方針

## 目的と収益モデル

- 主な収益源は **自作BGMの Content ID 収益**。TuneCore Japan で配信し、YouTube コンテンツ収益化サービス（Content ID）に登録する。
  - 自分のチャンネルを **除外リスト（ホワイトリスト）に入れない**。自分の動画に申し立てが付き、TuneCore 経由で収益が入る形にする。
  - 手数料は YouTube 収益の 20%。
  - 将来チャンネルを収益化（YPP）したくなったら、この設定と衝突するので見直す。
- ショート動画そのものの広告収益（クリエイタープール）は狙わない。
  - 参考：2027年2月から、ショートの収益分配には「直近90日でショート1000万回再生」が毎月必要になる。
- ショートで再生数が伸びたら、将来の選択肢として長尺の「朗読まとめ」動画（通常動画の分配率は 55%）を検討する。

## 動画の長さ

- **59秒以下を厳守**。Content ID の申し立てが付いた1分超のショートはブロックされ、収益化の対象外になる。

## プラットフォームの規約

- YouTube の「オーセンティックでないコンテンツ」（量産型・繰り返し）規定に注意する。人の手を必ず入れる：
  - 物語の選別と修正（story-guidelines.md）
  - 絵柄とシリーズとしての一貫性
  - 自作BGM
- テンプレートだけを変えた大量投稿はしない。投稿ペースは質を確認できる範囲に抑える。
- Instagram Reels は集客用。日本では広告収益の分配はほぼ期待しない。

## 権利と表記

| 素材 | 方針 |
|---|---|
| 声 | COEIROINK / AivisSpeech（D-011）。声ごとに規約を確認し、`config.yaml` の `credit` に規約どおりの表記を書く（説明文と画面に出る） |
| 画像 | ローカルで生成。商用利用できるモデルのみ（decisions.md にライセンスを記録） |
| フォント | 動画への埋め込みが許可されたもの（OFL など） |
| BGM | 自作のみ。詳細は bgm.md |
| 物語 | AIが下書きし、人が直す。既存作品の筋やオチを流用しない |

## 投稿

- 予約投稿で、まとめて上げて毎日決まった時間に公開する。`python -m ai_shorts upload` で上げる（decisions.md D-015）。YouTube Studio から手で上げてもよい。
- 投稿するのはユーザーが頼んだときだけ。勝手に投稿する仕組みは作らない。YouTube Data API で使う権限は `youtube.upload` だけ。
